# Changelog

## 1.1.1
- Added complete player intelligence profiles with session, world, ping/TPS, punishment, report, note, case, activity, identity, and optional economy/permission context.
- Added persistent case management, investigation sessions, case timelines, and evidence snapshots.
- Added recent activity capture for chat, redacted commands, combat, teleports, joins, and quits.
- Added configurable sensitive-command redaction.
- Expanded reports with categories, duplicate aggregation, automatic priority escalation, and staff workflows.
- Expanded Staff Mode with player inspector, reports, inventory inspection, freeze, vanish, recent activity, follow mode, and POV/spectate mode.
- Added Server Operations Center with performance, database, staff, maintenance, whitelist, announcement, and restart tools.
- Added granular permissions and optional Vault/LuckPerms support.
- Ensured StaffOps-rendered text is non-italic.
- Fixed case GUI lore construction, note record accessors, and Paper online-player generic conversion issues.
